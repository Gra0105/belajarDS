# 📊 Data Science Learning Journey

Selamat datang di repositori pembelajaran **Data Science** saya! Repositori ini berisi kumpulan kode, latihan praktis, eksplorasi data, serta implementasi algoritma Machine Learning yang saya pelajari dan kembangkan.

---

## 🎯 Tujuan Repositori

- **Dokumentasi Belajar:** Menyimpan alur dan perkembangan pemahaman saya dalam bidang Data Science dan Machine Learning.
- **Portofolio Kode:** Menjadi acuan praktis untuk proyek-proyek analisis data dan pemodelan prediktif.
- **Referensi Mandiri:** Memudahkan pencarian kembali kode *boilerplate*, manipulasi data, atau visualisasi yang pernah dibuat.

---

## 🛠️ Teknologi & Tools

- **Bahasa Pemrograman:** Python
- **Environment:** JupyterLab / Jupyter Notebook
- **Analisis & Manipulasi Data:** Pandas
- **Visualisasi Data:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn
- **Version Control:** Git & GitHub
